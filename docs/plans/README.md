# Plans

Implementation plans, written with the `write-plan` skill, reviewed with
`adversarial-review` (ledgers in [`../reviews/`](../reviews/)) and delivered
with `deliver-plan` ([`../DELIVERY.md`](../DELIVERY.md)). New plans go here as
`<NAME>_PLAN.md`.

A delivered plan stays here as the record of why the code is the way it is:
code comments and tests cite its decisions (D1…) and units (U1…) by path. The
living description of a feature is its reference doc in [`docs/`](../), not
the plan.
